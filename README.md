# EcoRecycle – E-Waste Management Website

EcoRecycle is a responsive multi-page frontend website focused on spreading awareness about electronic waste management and responsible recycling practices.

The project helps users:
- Learn about E-Waste recycling
- Find authorized recycling centers
- Schedule E-Waste pickups
- Contact recycling support teams

---

## Features

- Responsive multi-page website
- Modern UI using Bootstrap 5
- Hero section with CTA buttons
- E-Waste awareness section
- Recycling center listings
- Search/filter functionality
- Contact form
- Modal popup form
- Team & About pages
- Hover animations and transitions
- Mobile-friendly design
